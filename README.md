# Bobby / Dev Portfolio

A responsive, single-page portfolio for the MVR and PAL projects.

## Preview locally
Open `index.html` in a browser.

## Deploy
Import this folder/repository into Vercel, or upload the files to any static web host. No build step or package installation is required.

- MVR source: https://github.com/nails808/mvr
